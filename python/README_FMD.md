# FMD — обновление сайта для MSFO analyst

Распакуйте содержимое этого архива **внутрь существующей папки `MSFO analyst`**, рядом с `app_landing.py`, `data` и `baza_v2`. Исходный анализатор, Flask-приложение и ваши данные не заменяются. Для запуска нужен Python 3.10+.

## Первый запуск

```sh
python -m pip install -r requirements_fmd.txt
python deploy.py --serve
```

Откройте http://127.0.0.1:8000. Это локальная проверка. Для выхода нажмите Ctrl+C.

## Публикация в интернете из Python-файла

Самостоятельная публикация использует ваш аккаунт **Cloudflare Pages** и Node.js LTS с npm/npx. Один раз создайте аккаунт Cloudflare и выполните:

```sh
python deploy.py --setup --project fmd-financial-multiples
```

Откроется вход в Cloudflare; затем скрипт создаст проект, соберёт сайт и загрузит его. Имя проекта можно заменить своим. Если проект уже существует, используйте следующую команду без `--setup`.

Повторная публикация после изменения данных или интерфейса:

```sh
python deploy.py --project fmd-financial-multiples
```

Адрес сайта выведет Cloudflare после успешной загрузки. Это отдельный хостинг от опубликованного в ChatGPT сайта; команда не обновляет адрес `chatgpt.site`. Самостоятельная публикация в ваш аккаунт в ходе подготовки архива не выполнялась: для неё нужен ваш вход. Cloudflare Pages публикует файлы для посетителей; доступ к платной базе необходимо настраивать отдельно до коммерческого запуска.

Только сборка, без входа и публикации:

```sh
python deploy.py --build-only
```

Результат — папка `fmd_public`. Исходники интерфейса — `fmd_web`.

## Данные и обновление

- `baza_v2/01_base/agr_base.xlsx`: финансовые показатели, обычная и альтернативные EBITDA, история 2023–2025.
- `data/landing_data.json`: сохранённая история котировок, капитализация в валюте отчётности, ссылки на подтверждения. Обновляйте этот файл существующим загрузчиком проекта перед повторной публикацией. Скрипт публикации сам котировки не запрашивает.
- `baza_v2/03_Отчетность_и_скриншоты`: отчёты и подтверждающие скриншоты.
- `baza_v2/04_МСФО_Excel`: файлы финансовой отчётности по компаниям.

Скрипт не читает `.env`, не запускает анализатор и не переносит venv, ключи или логи на сайт. В публичную сборку входят только интерфейс, нормализованные финансовые данные и найденные финансовые документы. Не помещайте конфиденциальные файлы в папки источников для публикуемой базы.

## Что работает

Поиск по названию/тикеру через запятую; отраслевые и числовые фильтры; фильтр валюты; сортировка; медиана мультипликаторов; карточка компании с фактической историей; рентабельность и CAGR; сохранённые котировки; источники справа; Excel и ZIP по текущей выборке или отмеченным компаниям.

В Excel указаны валюта, даты, параметры и состав выборки медианы. ZIP содержит выбранную базу, котировки, первичные документы и скриншоты. Большая выборка может собираться дольше, прогресс отображается на сайте.

## Ограничения исходных данных

В поставке 29 компаний. Цены сохранены на 18.09.2026, отчётность — 2025. Сайт не является онлайн-потоком и не заявляет внешнюю верификацию архива. Пропуски не заменяются нулём или восстановленными значениями.

Финансы показаны в миллиардах валюты отчётности. Долларовые суммы не подписываются рублями. Обычная EBITDA не подменяется скорректированной, OIBDA или показателем до IFRS 16. Для Норникеля использована EBITDA МСФО в USD, рублёвая EBITDA эмитента не смешивается с ней. EV — упрощённо капитализация + чистый долг; отсутствующие составляющие не подставляются. P/E и EV/EBITDA не рассчитываются при неположительном знаменателе. Для банков EV и ND/EBITDA исключены, P/B отсутствует без загруженного капитала.

Загрузчик котировок исходного проекта использует CLOSE, при отсутствии LEGALCLOSEPRICE или WAPRICE. Вид цены в каждой строке кэша не сохранён, поэтому интерфейс подписывает её «Цена», а не гарантированная цена закрытия.

Логотипов компаний в исходной папке нет: в интерфейсе используются нейтральные инициалы. Подключение официальных логотипов, платежей, лицензий и пользовательских аккаунтов в это обновление не входит.
