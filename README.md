# FMD — Financial Multiples Database

Сайт для поиска и сравнения российских компаний, просмотра финансовых показателей и проверки первоисточников.

## Текущая версия

- 34 компании из `data/Database_v4_reconciled.xlsx`, версия базы от 13 октября 2026 года.
- Финансовые периоды: 2023, 2024, 2025, 1П2025, 1П2026 и TTM на 30.06.2026.
- Все суммы в рублях. В интерфейсе — млрд руб., цена акции — руб.
- Несколько отраслей у компании; поиск по отрасли, названию и тикеру.
- Настраиваемые диапазоны выручки, EBITDA, прибыли, капитализации и других показателей.
- Настраиваемые столбцы, сравнение выбранных компаний и медиана только в выборке.
- Рентабельность под соответствующим показателем, меньшим шрифтом и курсивом.
- Логотипы компаний, документы и официальные IR-страницы.
- Источники открываются в модальном окне; TTM показывает составляющие расчета.
- Выбор нескольких типов выгрузки: финансовые показатели, котировки, отчетность, IR-материалы, скриншоты.

## Развёртывание на Railway

Сервер написан на стандартной библиотеке Python, внешние пакеты не нужны.

Файлы `Procfile` и `railway.json` уже содержат нужные настройки:

- Build: Nixpacks, Python 3.11 (`.python-version`).
- Start: `python3 server.py`. Именно `python3`: образа Railway не содержит команды `python`, из-за чего контейнер падал с `python: command not found`.
- Healthcheck: `/health`.

Порт берётся из переменной окружения `PORT`, которую Railway задаёт сам. Если переменной нет, используется 5000 — это значение из раздела Networking вашего сервиса.

Переменная `HOST` намеренно **игнорируется**: сервер всегда слушает `0.0.0.0`. Если слушать только на `127.0.0.1`, прокси Railway не достучится до приложения и вернёт 502 с `connection refused`, хотя сам контейнер будет запущен.

Если порт в панели отличается от 5000, задайте `PORT` в Variables.

### Если сайт отдаёт 502

`connection refused` с нулевой длительностью означает, что в контейнере никто не слушает порт. Откройте логи сервиса в Railway — `server.py` печатает при старте версию Python, принятый `PORT`, значение `HOST` и результат проверки доступности порта. Типичные причины:

| Симптом в логах | Причина |
|---|---|
| `порт N не принимает внешние подключения` | Порт занят другим процессом; сервер повторяет попытку 5 раз |
| `index.html: ОТСУТСТВУЕТ` | Папка `public/` не попала в сборку; сайт отдаст 503 с текстом ошибки |
| `python: command not found` | В start-команде указан `python` вместо `python3` |
| Процесс завершился до `готов к работе` | Смотрите traceback выше в логах |


## Локальный запуск

```sh
python3 server.py
```

Сайт будет доступен на http://127.0.0.1:5000. Другой порт — `PORT=8080 python3 server.py`.

## Файлы проекта

- `server.py` — HTTP-сервер: раздаёт `public/`, отвечает на `/health` и `/api/session`.
- `public/index.html` — HTML страницы.
- `public/app.js`, `public/export.js`, `public/style.css` — интерфейс и выгрузка.
- `public/data.json`, `public/data.js` — подготовленные данные интерфейса (они должны совпадать).
- `public/assets/`, `public/logos/` — документы, страницы источников и логотипы.
- `data/Database_v4_reconciled.xlsx` — исходная книга; не публикуется как общая выгрузка сайта.
- `data/logo-sources.json`, `data/ir-materials.json` — происхождение логотипов и IR-ссылки.
- `scripts/sync-database.py` — чтение кэша книги и подготовка данных. Книга не изменяется.

## Обновление данных

Поместите актуальную книгу в `data/` и подготовьте папку исходных PDF. Для создания PNG источников требуется PyMuPDF (`pip install pymupdf`). Курсы для истории 2023–2024 уже зафиксированы в `data/currency-rates.json`.

```sh
python3 scripts/sync-database.py --workbook data/Database_v4_reconciled.xlsx --sources /path/to/reports
```

Скрипт читает сохраненные результаты формул из XLSX. Перед синхронизацией книга должна быть пересчитана в том процессе, в котором она ведется. Отсутствующие значения сохраняются как пропуски. Названия документов и страницы берутся из книги; неподтвержденные источники не подменяются. Скрипт выполняется локально и на Railway не запускается.

## Авторизация

Ранее сайт полагался на серверную авторизацию Sites / ChatGPT, которая работает только на платформе Cloudflare. На Railway её нет, поэтому `server.py` отвечает на `/api/session` как `authenticated: false`, а ссылка «Войти» возвращает на главную. Пароли и ключи в проекте не хранятся.

## Ограничения данных

Полная финансовая сверка исходной базы не завершена. График использует сохраненную историю котировок по 18.09.2026; цена в таблице берется из обновленной базы и рассчитана как средняя за 30 дней. Эти источники явно разделены в интерфейсе. Обычная и скорректированная EBITDA, IAS 17, EBITDAC и OIBDA хранятся отдельно. IR-страницы подтверждены для 32 из 34 компаний; отдельные IR-материалы Ozon и Сургутнефтегаза не прикреплены. Для части показателей исходный PDF или скриншот пока отсутствует.
