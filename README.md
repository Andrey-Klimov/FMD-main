# FMD — Financial Multiples Database

Сайт для поиска и сравнения российских компаний, просмотра финансовых показателей и проверки первоисточников.

## Текущая версия

- 34 компании из `data/Database_v4_reconciled.xlsx`, версия базы от 13 октября 2026 года.
- Финансовые периоды: 2023, 2024, 2025, 1П2025, 1П2026 и TTM на 30.06.2026.
- Все суммы в рублях. В интерфейсе — млрд руб., цена акции — руб.
- Несколько отраслей у компании; поиск по отрасли, названию и тикеру.
- Настраиваемые диапазоны выручки, EBITDA, прибыли, капитализации и других показателей.
- Настраиваемые столбцы, сравнение выбранных компаний и медиана только в выборке.
- Рентабельность под соответствующим показателем, меньшим шрифтом и курсивом.
- Логотипы компаний, документы и официальные IR-страницы.
- Источники открываются в модальном окне; TTM показывает составляющие расчета.
- Выбор нескольких типов выгрузки: финансовые показатели, котировки, отчетность, IR-материалы, скриншоты.

## Запуск

Node.js 22.13 или новее, pnpm 11.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Приложение использует Vinext и серверную авторизацию Sites / ChatGPT. В опубликованной версии платформой проверяется доступ к сайту и передается подтвержденная идентификация посетителя. Серверная страница перенаправляет анонимного посетителя на вход; `/api/session` возвращает состояние текущего аккаунта. Пароли не хранятся в проекте. Для независимого размещения вне Sites потребуется подключить поддерживаемый провайдер авторизации; GitHub Pages не исполняет серверную часть.

## Проверка и сборка

```sh
node tests/frontend.test.cjs
pnpm build
```

Автоматические проверки покрывают данные, фильтры, отрасли, выборку, медиану, рентабельность, периоды источников, состав Excel и пути к файлам. Проверка интерфейса в настоящем браузере в этой среде недоступна.

## Файлы проекта

- `public/app.js`, `public/style.css` — интерфейс.
- `web/shell.html` — HTML страницы.
- `app/route.ts`, `app/api/session/route.ts` — серверная страница и состояние аккаунта.
- `public/data.json`, `public/data.js` — подготовленные данные интерфейса.
- `public/assets/`, `public/logos/` — документы, страницы источников и логотипы.
- `data/Database_v4_reconciled.xlsx` — исходная книга; не публикуется как общая выгрузка сайта.
- `data/logo-sources.json`, `data/ir-materials.json` — происхождение логотипов и IR-ссылки.
- `scripts/sync-database.py` — чтение кэша книги и подготовка данных. Книга не изменяется.
- `python/` — предыдущая версия инструментов; основной интерфейс находится в `public/`.

## Обновление данных

Поместите актуальную книгу в `data/` и подготовьте папку исходных PDF. Для создания PNG источников требуется PyMuPDF. Курсы для истории 2023–2024 уже зафиксированы в `data/currency-rates.json`.

```sh
python scripts/sync-database.py --workbook data/Database_v4_reconciled.xlsx --sources /path/to/reports
```

Скрипт читает сохраненные результаты формул из XLSX. Перед синхронизацией книга должна быть пересчитана в том процессе, в котором она ведется. Отсутствующие значения сохраняются как пропуски. Названия документов и страницы берутся из книги; неподтвержденные источники не подменяются.

## Ограничения данных

Полная финансовая сверка исходной базы не завершена. График использует сохраненную историю котировок по 18.09.2026; цена в таблице берется из обновленной базы и рассчитана как средняя за 30 дней. Эти источники явно разделены в интерфейсе. Обычная и скорректированная EBITDA, IAS 17, EBITDAC и OIBDA хранятся отдельно. IR-страницы подтверждены для 32 из 34 компаний; отдельные IR-материалы Ozon и Сургутнефтегаза не прикреплены. Для части показателей исходный PDF или скриншот пока отсутствует.
